# Archive

Implemented plans removed from the source repositories on 2026-11-15: `backend/` holds the backend phase plans (7–14, 16–21), `frontend/` the frontend phase plans (F6–F11, F13–F20, F22).

They are kept as historical reference for design rationale: why something was built the way it was, and which alternatives were rejected. They are not maintained. The code and `tech-design.md` are the source of truth; where an archived plan disagrees with them, the plan is out of date.

This folder is not synced to the sources: it is neither pulled nor pushed, and its files are not restored to the sources' `docs/`.
